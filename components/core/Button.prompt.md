Mextas action button — white solid for the main CTA, white outline for the secondary, blue accent inside dark panels.
```jsx
<Button arrow onClick={openForm}>Solicitar propuesta</Button>
<Button variant="secondary">Ver soluciones</Button>
```
Variants: primary, secondary, accent, ghost, link. Sizes sm/md/lg. `arrow` adds the → that slides 3px on hover. Max one primary per view region.
